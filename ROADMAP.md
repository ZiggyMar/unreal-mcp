# Roadmap

Things planned beyond the current milestones, roughly in the order they make sense.

## Near-term

- **Live-editor verification pass.** Every milestone so far is build-verified and protocol-verified but has never run inside a real, open Unreal Editor session. This is the priority before anything below: distributing or promoting a plugin that's never actually been clicked through would be a mistake.
- **M4+**: informed by [docs/COMPETITIVE_LANDSCAPE.md](docs/COMPETITIVE_LANDSCAPE.md) once that survey lands.

## Distribution

- **Fab (Epic's marketplace)**: free listing, once live-verified. Code plugins are distributed as a zipped plugin folder; see [Fab's asset structure requirements](https://dev.epicgames.com/documentation/fab/asset-file-format-and-structure-requirements-in-fab?lang=en-US) and [publishing for free download](https://dev.epicgames.com/documentation/fab/publishing-assets-for-sale-or-free-download-in-fab). Needs an Epic developer account and goes through Fab's review, so budget time for that.
